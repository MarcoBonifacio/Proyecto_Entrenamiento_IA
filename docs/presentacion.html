Presentación General y Flujo Full-Stack de EcoClasifica

Docker Hub: yury1289/ecoclasifica:latest
❌ Problemática Identificada

Contaminación cruzada en puntos limpios

La ciudadanía tiene dificultad para reconocer el material exacto de un residuo sólido (plásticos, metales, vidrio, papel, cartón o basura general), reduciendo el aprovechamiento de reciclables.

🎯 Objetivo del Sistema

Clasificación asistida por IA + Guía Ecológica

Clasificar automáticamente fotografías de residuos en 6 categorías mediante un modelo ResNet-50 afinado, expuesto por una API REST FastAPI y una SPA React con recomendaciones de reciclaje.

👥 Público Objetivo

Ciudadanía, Estudiantes e Instituciones

Estudiantes universitarios, hogares, puntos de acopio municipal y programas de educación ambiental que requieren una herramienta portable en Docker.

🔗 Integración de Componentes en Producción (Puerto 8000)
1. Frontend SPA (/ui)
React 19 + Vite compilado en frontend/dist. Subida, Drag&Drop, Cámara o Ctrl+V.
2. FastAPI (:8000)
Recibe en POST /classify o /classify/base64 y aplica 6 validaciones de seguridad.
3. Preprocesamiento
AutoImageProcessor cacheado: convierte a RGB, recorta a 224×224 y normaliza (ImageNet).
4. Inferencia ResNet-50
EcoClasificaModel (singleton en _MODEL_CACHE) calcula logits y aplica Softmax.
5. Post-procesamiento
Traduce etiqueta a español, asigna emoji, desglose de 6 clases y consejo de contenedor.

Diapositiva 3 · Requisito 2 de la Rúbrica (Validación y Lógica)

Condiciones, Validaciones y Reglas de Negocio

Defensa en profundidad + Clean Code (Sin Magic Numbers)
🛡️ 1. Condiciones de Validación de Entrada (src/fastapi_app.py)
Tamaño de Archivo Binario: Mínimo > 0 bytes (`TAMANO_MINIMO_BYTES = 1`). Máximo 10 MB (`10,485,760 bytes`).
HTTP 400 / 413
Tamaño y Formato Base64 (`/classify/base64`): No vacío, máx. 15 MB de cadena y decodificación estricta (`validate=True`).
HTTP 400 / 413
Condición de Tipo MIME (`TIPOS_MIME_PERMITIDOS`): Solo image/jpeg, image/jpg, image/png, image/webp, image/bmp.
HTTP 400
Condición de Extensión (`EXTENSIONES_PERMITIDAS`): Solo .jpg, .jpeg, .png, .webp, .bmp (bloquea .pdf, .exe, .txt).
HTTP 400
Inspección de Magic Bytes (`Pillow Image.verify()`): Verifica la firma binaria real para impedir archivos falsificados con extensión .png.
HTTP 400
Rango de Resolución (`10×10` a `8192×8192` px): Rechaza imágenes diminutas (<10px) o bombas de descompresión (>8192px).
HTTP 400
⚙️ 2. Condiciones de Lógica de Negocio e Inferencia
  • • Carga Condicional del Modelo (`src/model.py`): Si Path(ECOCLASIFICA_MODEL_PATH).exists() es verdadero, carga el checkpoint afinado (is_finetuned = True); si no existe, activa el fallback descargando microsoft/resnet-50 base sin romperse.
  • • Caché Singleton (`_MODEL_CACHE` y `@lru_cache`): Evita recargar los 94.3 MB de ResNet-50 y el AutoImageProcessor en cada petición HTTP.
  • • Penalización por Baja Resolución (`src/ecoclasifica.py`): Si max_dimension < 128 (LOW_RESOLUTION_THRESHOLD), multiplica la confianza base (0.85) por 0.8 (CONFIDENCE_ADJUSTMENT) = 0.68.
  • • Normalización de Probabilidades (`classifyApi.ts`): Si un valor numérico es > 1, lo divide entre 100 (`Math.min(n / 100, 1)`); ordena el desglose de mayor a menor porcentaje.
  • • Montaje Condicional de UI (`src/fastapi_app.py`): Si (FRONTEND_DIST_DIR / "index.html").is_file() existe, habilita GET /ui y sirve los assets de React.

Diapositiva 6 · Requisito 3 de la Rúbrica (Componente de IA)

Modelo ResNet-50: Justificación, Entradas/Salidas y Limitaciones

Accuracy: 58.42% · F1 Macro: 0.4709
1. Identificación y Justificación

Modelo: microsoft/resnet-50 (50 capas convolucionales con conexiones residuales skip connections).

¿Por qué ResNet-50? Equilibrio ideal entre precisión y baja latencia en CPU. El transfer learning desde ImageNet-1k aprovecha extractores de texturas, brillos y bordes sin requerir millones de fotos ni GPU en producción.

2. Datos de Entrada (Input Tensor)

• Fotografía en formato JPEG, PNG, WEBP o BMP.
• Conversión a 3 canales RGB.
• Redimensionado y recorte central a 224 × 224 px.
• Normalización ImageNet:
  media = [0.485, 0.456, 0.406]
  std = [0.229, 0.224, 0.225]
• Tensor final: torch.Size([1, 3, 224, 224]).

3. Limitaciones Actuales del Modelo

• Entrenado solo por 5 épocas en CPU sobre TrashNet (2,527 imágenes con fondo blanco/limpio).
• Baja precisión ante fondos complejos, poca iluminación o múltiples objetos superpuestos.
• Clasifica por material visual, no detecta si el envase está contaminado con grasa/comida.
• La clase trash es heterogénea y no hay umbral de rechazo duro.

Diapositiva 7 · Requisito 4 de la Rúbrica (Implementación de Docker)

Dockerfile, Docker Compose y Despliegue desde Docker Hub

Puerto 8000:8000 · Healthcheck Activo
1. Explicación del Dockerfile
FROM python:3.11-slim
ENV PYTHONDONTWRITEBYTECODE=1 PYTHONUNBUFFERED=1 \
    ECOCLASIFICA_MODEL_PATH=/app/models/ecoclasifica-resnet50 \
    ECOCLASIFICA_FRONTEND_DIST=/app/frontend/dist
RUN apt-get update && apt-get install -y --no-install-recommends \
    libgl1 libglib2.0-0 && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY src/ ./src/
COPY frontend/dist/ ./frontend/dist/
COPY models/ecoclasifica-resnet50/ ./models/ecoclasifica-resnet50/
EXPOSE 8000
CMD ["uvicorn", "src.fastapi_app:app", "--host", "0.0.0.0", "--port", "8000"]

Punto clave sobre los pesos: models/ se excluye en .gitignore (~94.3 MB), pero se incluye dentro de la imagen publicada en Docker Hub yury1289/ecoclasifica:latest.

2. Uso de Docker Compose (docker-compose.yml)
services:
  ecoclasifica:
    build:
      context: .
      dockerfile: Dockerfile
    image: ${DOCKER_IMAGE:-yury1289/ecoclasifica:latest}
    container_name: ecoclasifica
    ports:
      - "8000:8000"
    environment:
      - ECOCLASIFICA_MODEL_PATH=/app/models/ecoclasifica-resnet50
      - ECOCLASIFICA_FRONTEND_DIST=/app/frontend/dist
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 15s
    restart: unless-stopped
